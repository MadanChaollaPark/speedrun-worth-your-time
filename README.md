# Worth Your Time

A free tool for job seekers deciding whether an early-stage or first-hire role is actually worth applying to. Built as the product idea for Madan Chaolla Park’s application to the a16z speedrun talent team Product Engineer contractor role.

This repository is being built by an autonomous plan → build → review loop on a private box. The application form itself will **not** be submitted from this work.

## Status

The first complete product, tests, and public GitHub Pages link will land in later commits. See `RESEARCH.md` for the job-post research and `GOAL.md` for the brief.

## Run and test

Documented here once the app exists. The loop driver reads `STATE/TEST_COMMANDS` (one shell command per line, run from the repo root).
